Sum Thing V.1.0 (Reconstructed)

Simple terminal-based maths game. Made to practice my beginner python.
Features:

Addition, subtraction, multiplication and division questions picked at random.
Customisable minimum and maximum values for the 2 numbers.
(Glitched) statistics.

I lost access to the original source code for v1.0 because I didn't think to back it up.
For that reason, the v1.0 source code is a reconstruction based on my memory and the .exe file.
The exe file is completely accurate though.
